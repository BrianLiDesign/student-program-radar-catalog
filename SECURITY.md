# Security Policy

## Reporting a vulnerability

Please report vulnerabilities through GitHub's private vulnerability reporting feature for this repository. Do not open a public issue for credentials, exploitable scraper behavior, workflow permission problems, or other sensitive findings.

Include the affected file or workflow, reproduction steps, expected impact, and any suggested mitigation. The maintainer will acknowledge the report and coordinate remediation and disclosure.

## Supported version

Security fixes apply to the current `main` branch and the latest published catalog release.
